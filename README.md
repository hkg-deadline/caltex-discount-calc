# 香港加德士油價折扣計數機

[![HTML5](https://badges.aleen42.com/src/html5.svg)](https://badges.aleen42.com/src/html5.svg)
[![JavaScript](https://badges.aleen42.com/src/javascript.svg)](https://badges.aleen42.com/src/javascript.svg)
[![TailwindCSS](https://badges.aleen42.com/src/tailwindcss.svg)](https://github.com/tailwindlabs/tailwindcss)

此是網站「加德士油價折扣計數機」（下稱「本網站」）的源始碼儲存庫。

本網站主要供香港燃油及混能私家車車主及司機計算使用加德士私人能源卡（能源大法）下的入油量、其實際支付金額、油價及折扣。

## 資料來源

本網站的車用汽油價格資料來自香港消費者委員會的油價資訊通（經[開放數據平台](https://data.gov.hk)及以[hk-petrol-price-crawler](https://github.com/hkg-deadline/hk-petrol-price-crawler)存取）。

## 使用方法

本網站由HTML、JavaScript及CSS構成，無需要編譯。

只需要上載完整源始碼至Web容器（Web Container）即可使用。

## 網站預覽
請瀏覽 https://hkg-deadline.github.io/caltex-discount-calc/
